## New UI/UX premise: replace in place on the M0–M5 spine

This is not a parallel portal, legacy reskin, country fork, or alternate V3. The new
UI/UX replaces active presentation in place on the architecture established through
the M0–M5 program: neutral `ida.*` entry, one login, session-owned context, canonical
role routes, case/recovery separation, and the existing governed domain boundaries.

The long-horizon presentation direction is one coherent Interdomestik experience:

1. public entry and guidance;
2. member home organized around case state and the next useful action;
3. agent work organized around assigned members and work;
4. staff operations organized around queues, decisions, and evidence;
5. admin control organized around governance and system state.

Only the first item is a candidate here, and only its active hero is in
`IDA-UI01a`. The roadmap is a design premise, not authority for concurrent dashboard,
navigation, route, shell, or design-system work. Existing behavior contracts are
inputs; the current glassy/card-heavy presentation is not the visual target.

session resolves, a signed-in V2 member sees continuation of existing work, not

## Accessibility and interaction contract

The first slice deliberately uses links rather than a stateful selector. That
removes ambiguous selected-state semantics and keeps the smallest implementation
native to the browser.

- one `h1`, descriptive text, and a semantic list of three links;
- unique accessible names that describe destination and purpose;
- DOM and visual order match: membership, self-guided help, case organization;
- minimum 44 by 44 CSS-pixel hit targets;
- minimum 16 CSS-pixel body copy on mobile and at least 8 CSS pixels between
  adjacent interactive targets;
- visible `:focus-visible` treatment using existing ring tokens;
- direct semantic links only; no interactive component may be nested inside a
  link;
- each secondary action uses one anchor around its complete heading,
  description, arrow, and padded row so the visible composition and the minimum
  44px target are the same interactive object;
- complete keyboard operation with Tab, Shift+Tab, Enter, and no focus trap;
- no color-only urgency or selection cue;
- no auto-rotation, carousel, or essential motion;
- `prefers-reduced-motion` produces no lost content or interaction;
- measured WCAG AA contrast of at least 4.5:1 for normal text and 3:1 for large
  text, component boundaries, and focus indicators;
- usable at 200% zoom and without horizontal overflow.
