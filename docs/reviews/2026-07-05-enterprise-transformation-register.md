## Register Maintenance Rules

1. **Runtime rows never self-promote.** A `CA+DG` row moving to `in_progress` requires the corresponding current-authority/design-gate record in `docs/plans/` first; this register links to it, never substitutes for it.
2. **`done` requires the evidence artifact path or PR**, not an assertion.
3. **Phase-boundary review:** at each phase end date, every `not_started` row gets a decision: carry, re-date (with reason), or `dropped(reason)`. Silent slippage is the register's failure mode.
4. **Blocked-chain check:** ENT-A01→A15, A02→B01, B04/B05→B06, C01/C02→C03 are the critical chains — review them weekly during Phase A/B.
5. **Stop conditions from the audit (§10) override every target date in this register.**
