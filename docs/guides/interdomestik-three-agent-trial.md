# Owner-authorized three-agent trial

Director prepares sequence/sizing/design briefs. Developer is the sole implementation
owner and coordinates external providers. Coach reviews process and evidence and
proposes verified lessons; product priority/next brief belongs to Director. Monitor
schedules deduplicated boundary checks. Arben chooses visual direction and material
tradeoffs and owns pilot/release approval.

Start at the current owner's clean delivery boundary; preserve current provider
processes and valid proof. Prepare one active slice and one next brief. Canonical
program/tracker remain the only execution authority.

Trial: three bounded slices with shared receipt metrics. Baseline: existing receipt
phase timestamps, correction/verification counts and observed journey responsiveness,
with unknowns explicit. Candidate: same measures plus planning overhead, mid-slice
scope changes, design rework, role/accessibility regressions and human visual feedback.
Do not sum overlapping time or infer causal speed gains from dissimilar slices.

The redesign brief covers shared shell primitives plus separate member/staff/admin/
agent configuration, preserving role/tenant permissions. Actual current screenshots
and three visual options precede owner selection and dependent implementation. The
older image is an inspiration source. Measured responsiveness accompanies each journey.

Canonical registration/source parity and fresh startup are pending until verified.
Explicit-read assessments do not prove named-role loader activation. Installed model
configuration is not independent backend attestation. Continue the existing monitor;
no second automation and no competing product writer.
